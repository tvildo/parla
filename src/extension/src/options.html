Privacy

If Parla ever fails on your computer (an error, a crash, a call without sound), this is the easiest way to let us know: one switch, no bug report to write, and we get what we need to fix it. Off unless you turn it on. It sends errors, performance and the kind of calling app, with a random ID that changes every month. Never audio, page content or addresses.

Also sends the domain of the site where Parla ran (for example meet.google.com, never the rest of the address) and a permanent random ID, so a problem on one site can be traced. Off unless you turn it on.
